# Kids' programme (Kids Club)

Weekly programme of the Kids Club: crafts, games, meals and times for each day. The German original is corrected, then the English version is produced with the original's design, graphics and layout. Plans rotate (e.g. plan 1–3), with summer and winter versions, sometimes in two variants (with and without a midday break).

## Workflow

1. Staff send the German .docx. **Yellow highlights** mark points to check.
2. **Check and correct the German** with the house corrections below. Check every date against its weekday.
3. **Build the English version** in the same file layout (copy of the German file, text replaced run by run).
4. Deliver as .docx only. File names carry the period and the language, e.g. `EN_10_10_-_16_10_Programme_2.docx`.
5. **Final check:** staff send all files again with "Is everything fine?", because unintended changes are possible. Compare DE and EN line by line.

Stay in one chat for the season while the context helps; switch only when token use gets too high.

Technique: Word splits words across several `<w:t>` nodes, so merge runs before any replacement or replacements fail silently. The German template has no separate runs for ordinal endings; the superscript st/nd/rd/th runs are created during translation. Picture overlaps in a PDF preview come from Word's image positioning, not from the text.

## German: house corrections (applied automatically)

- Kinder-Club → Kinderclub · Kinder-Menü → Kindermenü · IM SPIELZIMMER → IM KINDERCLUB
- Times: `09:00 Uhr` → `09.00 Uhr`; range with en dash: `09.00 Uhr – 10.00 Uhr`; "15 Uhr zum" → "15.00 Uhr zum"
- Dates without leading zero in the day and with a space: "07. Oktober" → "7. Oktober"; "7.Oktober" → "7. Oktober"; year range "2026 - " → "2026 – "
- German quotes „…" (not "…")
- Compounds: Mensch Ärgere Dich → Mensch ärgere dich · Monza Autorennen → Monza-Autorennen · Boden Mikado → Boden-Mikado · Klatsch Memory → Klatsch-Memory · Stopp-Tanz → Stopptanz · Kino-Abend → Kinoabend · Ballon-Tennis → Ballontennis · Neujahrs Bingo → Neujahrs-Bingo · "21" Gewinnt → „21" gewinnt
- Spelling: Pügelperlen → Bügelperlen · Renntiere → Rentiere · Quixx → Qwixx · Glückschweinchen → Glücksschweinchen · Daraus Basteln wir → Daraus basteln wir
- Craft items always in "Wir" form: "Basteln mit Wäscheklammern" → "Wir basteln mit Wäscheklammern" · "Mandala malen" → "Wir malen ein Mandala" · "Bemale Holzklammern" → "Wir bemalen Holzklammern"
- Questions get their question mark: "Wer trifft den Korb?" · "Wie weit kannst du werfen?"
- Standard texts in the approved wording (see below), e.g. "zum Kinderessen" → "zum Abendessen am Kindertisch".

## English: conventions

- Title always **"Children's Programme"**; club name **"Kids Club"** (two words, both capitalized, proper name).
- British English throughout (colours, programme).
- Craft items in "Let's" form (DE "Wir …").
- Numbers up to twelve spelled out.
- Times: German 24 h → 12 h with am/pm: `09.00 am – 10.00 am`, `12.00 pm – 03.00 pm`.
- Day headings: "Friday, October 16th, 2026"; title range "from October 10th" / "to October 16th, 2026". Ordinal endings (st, nd, rd, th) **always superscript**, in the day headings and the title.
- No German quotation marks in English ("…"), no accents used as apostrophes ( ' ).
- Holidays: Heiligabend → Christmas Eve · Christtag / 1. Weihnachtstag → Christmas Day · Stefanitag / 2. Weihnachtstag → Boxing Day · Silvester → New Year's Eve · Neujahr → New Year's Day.
- Heart wordplay: keep the ♥ symbol; „recht ♥-lich eingeladen" → "most ♥-ily invited", „♥-lich willkommen" → "♥-y welcome".

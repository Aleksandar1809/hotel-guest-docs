# French and Italian corrections in the skill

Checked against standard usage, not house habits. Files: `skill/hotel-guest-docs/` (references, examples, SKILL.md, script) and `docs/demo-script.md`.

## French

| Before | After | Why |
|---|---|---|
| Fromage national et international / du chariot | Fromages nationaux et internationaux / du chariot | Plural for an assortment (reference + script) |
| Sherry, Whisky, Rhum, Porto, Madère … capitalized | xérès, whisky, rhum, porto, madère … lower case; brands stay capitalized | Generic spirits are common nouns |
| Mascarpone, Parmesan, Dim Sum capitalized | mascarpone, parmesan, dim sum | Common nouns |
| purée à la X | purée de X | Standard construction |
| ragoût de fruits (dessert Röster) | compotée | Standard dessert term |
| Mousse de la banane (exception) | removed (Mousse de X) | Not standard |
| Semerrolle → quasi · Huft → quasi · Lende → aloyau | rond de gîte · quasi (veal) / rumsteck (beef) · filet | Correct cuts |
| Pointu de veau | pointe de culotte de veau | "Pointu" is not a cut |
| gelbe Rüben → navets jaunes | carottes | Austrian "gelbe Rüben" are carrots |
| chicorée Witloof | endives | Usual French term |
| Bratkäse → fromage fondu | fromage grillé | "Fondu" means processed cheese |
| Plunderteig → pâte feuilletée | pâte feuilletée levée | Danish pastry is leavened |
| Distelöl → huile de chardon | huile de carthame | Distelöl is safflower oil |
| Serviettenknödel → boulette en serviette | boulette de pain en serviette | Clearer |
| Kids' menu: doré (never panés) | pané(e) | Standard for breaded |
| à la sauce « Bolognese » | sauce bolognaise | French spelling |
| Flammerie (FR) | flan | "Flammerie" is not French |
| Examples: salade de concombre, Selle de cerf rosée, Parmesan, purée à la patate douce, Escalopes … dorées, Flammerie au fromage frais, ragoût d'abricots | salade de concombres, Selle de cerf rôtie rosée, parmesan, purée de patate douce, Escalopes … panées, Flan au fromage frais, compotée d'abricots | Applied the rules above |

## Italian

| Before | After | Why |
|---|---|---|
| con diverse vinaigrette e guarnizioni | con diversi condimenti e guarnizioni | Italian term |
| Sherry, Madera, Marsala, Porto … capitalized | lower case; brands stay capitalized | Common nouns |
| espuma / ed espuma | spuma / e spuma | "Espuma" is Spanish; "ed" only before e |
| rosa → rosé | cotto/a rosa | Italian doneness term |
| un brasato | brasato | No article in a dish line |
| Ragout (dessert) → ragoût | composta | Italian term |
| Lende → lombo · Huft → noce | filetto · scamone | Correct cuts |
| gelbe Rüben → rape gialle | carote | Austrian "gelbe Rüben" are carrots |
| Plunderteig → pasta danese | pasta sfoglia lievitata | Standard term |
| Distelöl → olio di cardo | olio di cartamo | Safflower oil |
| Kids' menu: rosé · sfoglia di patate · radici a losanghe · malto | cotto rosa · patate duchessa · ortaggi a radice a losanghe · maltodestrina | Standard terms |
| Vi consigliamo / l'odierno menù / Vi consiglia | vi consigliamo / il menù di oggi / vi consiglia | Modern standard, more natural |
| Examples: Lombata di cervo rosé, Canederli di albicocche | Lombata di cervo cotta rosa, Canederli alle albicocche | Applied the rules above |
